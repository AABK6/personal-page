# Tech Stack

## Overview
This project does not enforce a rigid, bounded technology stack. Instead, the stack is highly adaptable and flexible, to be determined on a per-project or per-track basis depending on what is deemed best for the specific task at hand.

## Baseline Technologies
While flexible, the existing foundation includes:
- **Languages:** HTML, CSS, JavaScript, Python
- **Frontend:** Vanilla HTML/CSS/JS (Canvas API), adaptable to modern frameworks as needed.
- **Backend/Data:** Python with libraries like `pandas` and `google-genai`.

## Guiding Principle
- **Best Tool for the Job:** Future developments, tracks, and new features will utilize whatever technology stack is most appropriate and efficient for achieving the desired outcome.
